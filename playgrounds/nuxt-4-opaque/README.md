# Nuxt 4 playground: opaque sessions

> [!WARNING]
> Under development. The code is the reference; this README is not maintained yet.

`unauth/n` signs in; the application keeps its own sessions: a row in sqlite, an opaque token in the cookie.

```sh
pnpm install
pnpm dev:prepare
pnpm dev:nuxt-opaque
```

Run from the repository root.
